1. Le projet et le besoin

Notre projet est un bot Discord pour les élèves de l'ESGI. À l'origine, nous voulions un bot simple, sans intelligence artificielle, pour gérer les devoirs et l'agenda des B1.

Le problème est simple : depuis que nous sommes à l'ESGI, nous n'avons plus d'agenda ni de Pronote comme au lycée. Les devoirs et les dates d'évaluation sont donnés à l'oral ou envoyés sur Discord, et ils se perdent vite au milieu des autres messages. Résultat : on oublie des devoirs et tout le monde n'a pas les mêmes informations.

Objectifs

  • Pouvoir ajouter et voir les devoirs de la classe directement sur Discord.
  • Recevoir des rappels avant les dates importantes.
  • Plus tard, créer des rôles par élève, par classe et par matière, pour toute l'ESGI.
  • Enfin, faire un site web pour gérer le bot plus facilement.

2. Notre solution

Tous les élèves utilisent déjà Discord tous les jours. Plutôt que de créer une nouvelle application, nous mettons l'agenda directement dans Discord : il n'y a rien à installer.

Pour ajouter un devoir, l'élève tape la commande /ajouter_un_devoir, choisit la matière dans une liste, puis entre la date et le sujet. Le bot vérifie la date et enregistre le devoir dans une base de données. Les devoirs ne se perdent plus, et le bot pourra prévenir la classe avant la date.

Nous avons aussi ajouté un petit easter egg, le « Thomson », un clin d'œil à notre représentant pédagogique : de temps en temps, le bot répond avec une phrase et une image au hasard.

3. Partie technique

Technologies

  • Python avec la bibliothèque discord.py pour le bot.
  • SQLite pour la base de données (devoirs, membres, configuration).
  • VS Code et PyCharm pour coder, Git et GitHub pour travailler à deux.

Fonctionnement

Le code est découpé en plusieurs fichiers (appelés « cogs ») : un pour les commandes, un pour les messages, un pour les rappels et un pour la base de données. Chacun peut travailler sur une partie sans gêner l'autre.

4. État de l'art

Nous avons regardé ce qui existe déjà :

  • MEE6 et Carl-bot : des bots Discord très connus qui gèrent bien les rôles, mais pas les devoirs.
  • Sesh et Apollo : des bots Discord pour les calendriers et les événements, mais sans notion de classe ou de matière.
  • Pronote : un cahier de textes complet au lycée, mais pas utilisé à l'ESGI et en dehors de Discord.
  • Google Classroom : gère les devoirs, mais seulement si les professeurs l'utilisent.
